# 界面工作区调整

针对用户提供的 Windows 截图，解决大顶栏、重复数据概览、首页说明过多，以及操作区域被挤到左下方的问题。只调整 HighDimClusterSystem，在独立分支完成；算法和导出代码没有重写。

## 当前界面

- 顶栏 56 像素，单行导航 44 像素；两者合计从 194 缩至 100 个逻辑像素。
- 使用浅色背景、普通字重和克制的紫色强调。去掉英文副标题、导航编号、大标题和宣传面板。
- 右侧数据概览默认收起，通过顶栏按钮展开；默认主工作区占中央区域至少 98% 的宽度。
- 首页展示真实数据预览、四个简洁指标和四个分析入口，不再显示“分析能力”及冗长流程说明。
- 数据页使用紧凑工具栏和“数据 / 变量概况”标签页。六种清洗与标准化操作均保留在预处理选择器中，恢复原始数据仍可直接操作。
- 特征统计、PCA、降维、聚类使用 280 像素参数栏与大结果区。参数独立滚动，执行按钮固定在参数栏底部；表格和图表从工作区顶部开始展示。
- 降维的历史记录/对比放到独立标签页；评价页分为聚类对比与 K 扫描，避免多块大面板纵向堆叠。
- 表格显示六位有效数字，悬停可见完整原始数值；存储、计算和文件导出保留原精度。热力图底部标签已增加空间，避免裁切。
- 算法结果使用简短状态行，详细评分条件保留在提示、指标表和导出中；DBSCAN 明确显示评价不含噪声。

## 验证

完整测试 127 项通过：原有数值算法测试保持不变，新增 11 项工作区与真实操作测试。新测试验证三种窗口尺寸下可见数据表格至少占窗口一半高度、所有六种预处理操作产生正确结果、原始数据与恢复功能不受影响、参数不越界，以及显示格式不改变数值。

两份原有布局测试针对旧设计硬编码了右栏必须常驻、工作区占 80%–84%、两列宣传区域比例和高导航按钮。根据用户要求，改为检查概览默认收起/可展开、工作区至少 98% 宽、导航高度不超过 40 像素、真实入口跳转及所有功能页的可用区域。这些检查没有跳过、禁用断言或修改算法结果。

真实功能验收使用仓库 90 行人工示例数据：PCA、因子分析、MDS、t-SNE、三种聚类、评价和 K 扫描均实际执行；36 张结果表、9 张图表成功导出，CSV/Excel 读回一致。产生了各主要功能、导出状态和不同窗口尺寸的实际运行截图。

当前截图来自 Linux Qt 运行环境，使用 Noto CJK 字体；1536×864 布局代表 1920×1080 / 125% 的等效逻辑尺寸，不能冒充 Windows 11 实机 DPI 验收。Windows 原生字体与新 EXE 验收仍需执行已有验证脚本。

GitHub 的 Windows 构建此前被账户付款/Actions 支出上限阻止启动，尚未生成此界面的新 EXE。没有删除任何其他项目的产物或源代码。
