# 高维数据降维与聚类分析系统 V1.0
## 用户操作说明

软件名称：高维数据降维与聚类分析系统 V1.0

运行平台：Windows 10/11（64 位）。分析与导出在本地执行，不调用在线服务。
演示数据 data/sample_data.csv 为人工构造的测试数据，不代表公开科研实验数据。

### 一、启动软件

方式一：下载 GitHub Actions → Windows V1.0 Release Build 的成功构建附件
HighDimClusterSystem-V1.0-Windows。解压后保留完整目录，双击
HighDimClusterSystem.exe 启动。软件目前未进行商业代码签名，首次执行时应确认文件来源。

方式二：安装 Python 3.12，在项目根目录创建虚拟环境，并安装 requirements.txt 中的依赖，
最后执行 python main.py。关闭主窗口退出程序；分析任务运行期间请等待计算完成再退出。

### 二、功能导航

系统采用左侧导航栏，包含 8 页：分析首页、数据管理与预处理、特征统计分析、
主成分分析（PCA）、多方法降维、聚类分析、聚类评价与模型对比、结果中心。

推荐流程：导入数据 → 清洗与标准化 → 统计分析 → 降维/聚类 → 模型评价 → 导出结果。

### 三、数据管理与预处理

点击第 2 页“导入 CSV / Excel”，支持 CSV、XLSX、XLS 文件。导入后可查看行列数、
数值与非数值变量数量、缺失值和重复行数量、数据表格预览及逐列数据基本信息。

预处理支持删除含缺失值样本、数值列均值/中位数填补、重复行去除、Z-score 标准化、
Min-Max 归一化。操作均作用于当前工作数据，不直接更改磁盘原始文件。
通过“恢复原始数据”回到首次导入的数据副本。

### 四、特征统计分析

第 3 页选择数值变量，未选择时使用全部数值列。可计算描述性统计、
Pearson 相关系数矩阵、协方差矩阵，并绘制相关热力图、变量直方图、
箱线图和双变量散点图。直方图默认绘制所选第一个变量；
双变量散点图使用前两个变量；多变量箱线图最多显示 12 个变量。

### 五、主成分分析（PCA）

第 4 页选择数值变量，可开启 Z-score 标准化。
主成分数量可以自动按累计贡献率 85% 推荐、手动指定，或按自定义累计贡献率选择。
点击“执行主成分分析”后查看特征值、方差贡献率、累计贡献率、
主成分系数矩阵、相关载荷矩阵和主成分得分矩阵。
提供贡献率图、二维与三维主成分得分图。保留维数不足时不生成虚构图形。

请注意：主成分系数代表特征向量，相关载荷代表变量与主成分得分的相关系数。

### 六、多方法降维

第 5 页支持因子分析、MDS 多维尺度分析与 t-SNE。选择目标输出二维或三维空间。
因子分析可选择 varimax、quartimax 或不旋转，结果显示因子得分、
因子载荷及独特方差。MDS 可设置欧氏/曼哈顿距离、迭代次数与初始化次数，
显示距离残差指标。t-SNE 可设置 perplexity、学习率、迭代次数、随机种子，
显示 KL 散度与真实降维坐标。

分析记录支持两个同条件结果的并排对比。
不同方法专属评价指标并非同一含义，不应直接跨算法排序。

### 七、聚类分析

第 6 页支持 K-means、层次聚类和 DBSCAN。

K-means：设置 K、迭代次数与随机种子，输出每个样本的类别、
簇样本数、聚类中心和 SSE 惯性。
层次聚类：可选择 Ward、complete、average、single 连接方式，
选择欧氏或曼哈顿距离；Ward 仅允许欧氏距离。
DBSCAN：输入 eps、min_samples 和距离类型。标记 -1 为噪声，
不将其计为有效簇。

二维、三维聚类散点图使用 PCA 投影仅供可视化；聚类标签和评价分数
始终从选定的原始特征空间（及所选标准化方案）计算。

### 八、聚类评价与 K 值辅助选择

第 7 页显示已完成算法的评价对照。
轮廓系数与 Calinski–Harabasz 指数通常越大越好，
Davies–Bouldin 指数通常越小越好。
单个有效簇、全部噪声等不能评价的情形显示“不适用”。
DBSCAN 只对非噪声样本计算质量分数，解读时应结合噪声比例。

K 值扫描支持指定范围、随机种子与迭代参数，
生成真实 K-means SSE 肘部曲线和轮廓系数曲线；
系统给出的最大轮廓系数 K 只作为辅助建议。

### 九、结果中心与文件导出

第 8 页汇总当前数据版本已经生成的真实结果表。
下拉列表可选择并预览不同统计或模型结果（最多显示前 500 行）。

“导出所选表 CSV”：保存所选结果表的完整行数据。
“导出全部结果 Excel”：将不同结果表分成独立工作表。
“生成离线 HTML 分析报告”：生成包含真实数据与分析结果摘要的网页；
超长表格仅预览部分行列，完整数据以 Excel/CSV 导出为准。
“保存 PNG / SVG”：保存已有的真实绘图，不产生虚构图像。
“清空本次分析结果”：仅清空当前计算快照，不删除当前工作数据与原始文件。

导出文件均保存在用户自己选择的本地路径。

### 十、注意事项与常见问题

- 不要将样本 ID 或没有实际测量意义的数值编号直接作为算法特征；建议明确选择分析变量。
- PCA、因子分析及聚类通常要求至少两个有效数值变量，含缺失、无穷或常数列时需先清洗。
- t-SNE 的 perplexity 必须小于样本数，过大的样本表可能耗时较久。
- 复杂算法有内存上限，以防桌面应用因规模过大而崩溃。可在记录抽样方法后科学抽样。
- 导出的 HTML 是可离线查阅的报告，不依赖第三方网页组件。
- 若软件无法运行，检查完整压缩包是否解压、Qt 图形依赖是否完整，或改用 Python 源码启动验证。
- 软件截图可由项目的 Windows 构建流程从真实 GUI 生成，申请材料请使用与最终版本一致的截图。
- 当前应用未经商业代码签名。软件著作权登记需要独立开发、权属与材料一致性，最终由主管机构审核。
