# 第三软著界面差异化设计说明

本文件用于开发阶段的界面一致性检查，不作为软件运行时内容展示。

## 与已完成软件的结构区分

第三软件《高维数据降维与聚类分析系统 V1.0》采用独立的 **Data Studio** 视觉和布局：

- 主结构：**深色品牌顶栏 + 横向八模式导航带 + 全宽分析画布**。
- 首页：数据状态 Hero、四个数据指标块、分析路径、分析能力矩阵。
- 主色：墨紫 / 紫罗兰，辅以琥珀、玫瑰、薄荷色指标强调。
- 页面内容：轻量页标题带 + 白色分析面板；不使用固定侧栏作为主导航。

对照约束：

- 不采用多目标优化/Pareto 软件的左侧工作流导航、PARETO 品牌式侧栏结构。
- 不采用可靠性/风险软件的青绿色工业实验台配色、顶部模块下拉选择器和上一页/下一页控制条。
- 不复用上述两个软件的首页 Hero、指标卡命名、品牌标识、页面编号方式或主导航控件。

## 回归检查

`tests/test_ui_identity.py` 固定检查：

1. 八个功能页仍可正常切换；
2. 主窗口存在 `studioHeader` 与 `modeStrip`；
3. 八个导航项全部为横向 `modeButton`；
4. 主窗口不再存在 `sidebar`；
5. 首页真实指标块可由数据状态更新。

算法层、数据层、导出层不因界面重构而改变。
