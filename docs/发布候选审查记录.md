# 发布候选审查记录

范围仅 HighDimClusterSystem，独立分支 `release/readiness-review`。现有降维、聚类、评价、导出功能保留；没有从零重写、伪造结果或修改已有测试。新增测试专门复现本轮发现的缺陷。本记录不是正式 Windows 发布完成声明。

## 算法审查

| 模块 | 实际实现及审查结论 |
| --- | --- |
| 导入 | pandas 读取 CSV/Excel，UTF-8 BOM / GB18030 回退；拒绝空文件、未知扩展名、重复列名。原始与工作数据独立复制。 |
| 清洗 | dropna、真实均值/中位数填补、去重、StandardScaler/MinMaxScaler。修复填补传播无穷值的问题；标准化明确拒绝无穷值。 |
| PCA | scikit-learn 全 SVD，特征值/贡献率、系数、得分；相关载荷由模型系数和标准差计算。拒绝重复变量选择，避免重复特征改变统计权重。 |
| 因子分析 | FactorAnalysis 的真实模型载荷、得分、独特方差、平均对数似然；varimax/quartimax 来自库实现。 |
| MDS | 根据选定欧氏/曼哈顿距离构造完整距离矩阵，度量 MDS；独立重算真实距离残差和归一化 Stress。 |
| t-SNE | TSNE 的真实坐标与 KL 散度。250 次仅完成早期夸大阶段，会产生最大浮点值 KL；本轮将最低迭代数设为 300，并同步 UI/自检。 |
| K-means | KMeans，10 次初始化；标签、中心、惯性 SSE 来自模型。中心恢复原始量纲，SSE 仍属于参与聚类的特征空间。 |
| 层次聚类 | AgglomerativeClustering；真实 children/distances 构造树状图；Ward 仅支持欧氏距离。 |
| DBSCAN | DBSCAN 的真实标签，-1 为噪声，质量评价排除噪声并报告比例。 |
| 评价 | silhouette_score、davies_bouldin_score、calinski_harabasz_score；不适用时返回空指标。修复超过 1200 个有效簇时负抽样数量崩溃，保留 CH/DB，明确轮廓系数不适用。轮廓系数现跟随聚类距离选择；CH/DB 仍为欧氏中心指标，界面/导出说明明确。 |
| 导出 | 同版本实际结果快照；完整 CSV/Excel，离线 HTML，实际 Matplotlib PNG/SVG。临时文件完成后原子替换，保护电子表格公式文本。 |

所有算法继续使用真实库调用，不用随机占位数据或硬编码指标。核心算法已有数值基准和无效输入测试。投影只用于可视化，不参与聚类评价。模型专属指标不能混为跨模型排名。

## 修改与原因

- `core/clustering.py`：抽样边界和距离一致性；评价失败不再使已完成的聚类丢失。
- `core/dimension_reduction.py`、`app/dimension_page.py`、`tools/gui_self_check.py`：统一 t-SNE 有效迭代下限。
- `core/preprocessing.py`、`core/statistics.py`：无穷值清洗检查与重复变量拒绝。
- `app/fonts.py`、`main.py`、`tools/capture_screenshots.py`：从已安装字体检查中文字符，Qt 基础字体与 QSS 使用相同字体；缺失中文字体时明确报错。
- `app/plot_canvas.py`：图片尺寸不再参与反向撑大布局；按真实设备像素比渲染，调整窗口时延迟合并重绘。
- `app/studio_components.py`：紧凑顶部间距，像素宽度省略长名称，完整名称保留在提示中。
- `app/main_window.py`：默认尺寸参考当前屏幕可用区域，保持原有最小窗口约束。
- `tools/verify_release.py`：附件比较由只检查 sklearn DLL 哈希扩大到所有文件。
- `tools/release_acceptance.py`、`tools/verify_windows_release.ps1`：真实功能、截图、导出、原生 Windows DPI、打包及 EXE 验收；失败保留原始状态。
- `tests/test_release_regressions.py`、`tests/test_release_gui_regressions.py`：新增 10 项缺陷回归测试，已有测试内容保持原样。
- `.gitignore`：忽略截图和本地发布证据，避免提交生成文件。
- `README.md`、两份审查/验收文档：区分当前证据、历史 CI 及待执行的 Windows 验收。

## 当前验证证据

Python 3.12.14，PySide6 6.9.3，仓库固定版本依赖。`pip check` 无冲突，源文件编译通过，启动自检通过，8 个页面和 90 行 / 8 个数值变量加载正确。基线 106 项测试通过；新增回归后全部 116 项通过。另有 Pyparsing 依赖的弃用警告，未关闭警告或禁用断言。

Linux offscreen 真实功能验收产生 36 张结果表和 9 张可导出图表，CSV/Excel 读回一致，HTML/PNG/SVG 成功生成。40 张窗口截图包含各算法参数/结果/指标、导出状态和两种窗口尺寸；已检查代表性真实截图，修复图像控件撑大布局及名称截断。

示例数据为仓库人工构造的测试数据。真实计算记录：PCA 三分量累计贡献率约 96.93%，t-SNE（500 次、perplexity 15）KL 约 0.2083；K-means 轮廓系数约 0.7659，SSE 约 44.3449。具体值以本轮 `evidence.json` 为准，不把样例表现推广到其他数据。
